# Contributing

Pull requests only, against `main`. Family wrappers land as focused follow-up
PRs, one family or a small batch per PR.

This repo squash-merges every PR to `main`. **The PR title becomes the commit
subject on `main`** — individual branch commits are folded away.
[release-please](https://github.com/googleapis/release-please) only sees that
squash subject, so the PR title decides whether a release PR is opened.

### PR title rules

Releasable work **must** carry a [Conventional Commits](https://www.conventionalcommits.org/)
type in the PR title:

- `feat:` / `fix:` / `perf:` / `revert:` — triggers a release PR after merge.
  Add a scope when it helps: `feat(gallery): …`, `fix(ldrs): …`.
- `chore:` / `docs:` / `ci:` / `test:` / `style:` / `refactor:` — does **not**
  open a release PR. Use these for deps bumps (`chore(deps): …`), docs-only
  changes, CI tweaks, etc.

Examples: `feat: add gridora family`, `fix(gallery): meta tags for previews`.

Before merging, confirm that the GitHub squash-commit title still has the type
prefix — GitHub sometimes rewrites it to the branch name or a casual title if
the PR was renamed mid-review.

## Local setup

```bash
pixi install
npm install
pixi run build
pixi run test
```

Every pull request runs `.github/workflows/tests.yml`: it lints `src/`
(`pixi run lint`), rebuilds from source, fails if the committed build differs,
then runs the suite headless.
Locally, `pixi run test` is the same suite.

`pixi run build` compiles the JS bundle and regenerates the Python wrappers from
the React components. Use `pixi run build-js` when you have only changed React
or CSS under `src/`.

Do not hand-edit anything under `dash_loading_components/` except
`loading.py`, `registry.py`, the package `__init__.py` (which imports each
family namespace) and the family `__init__.py` files; the rest is
generated by `dash-generate-components` from `src/lib/components/`.

## Adding a family

1. Add the upstream package to `package.json` and to `docs/UPSTREAM-INVENTORY.md`,
   including its SPDX license and declared React peer range.
2. Add wrappers under `src/lib/components/<family>/`, one React file per
   component, prefixed with the family name, and export them from
   `src/lib/index.js`. If the upstream ships untranspiled ES modules, add it to
   the `exclude` pattern in `webpack.config.js`. Import what you render by name:
   a bare side-effect `import` can be tree-shaken out of the production bundle,
   so check in a browser test that the component really paints.
3. Export short names from `dash_loading_components/<family>/__init__.py` and
   import the namespace in `dash_loading_components/__init__.py` (both the
   `from . import` line and `__all__`).
4. Register the family in `dash_loading_components/registry.py`, including its
   native tempo prop and each spinner's normal tempo if it has one.
5. Add the family to `NOTICE`.
6. Add it to the gallery in `gallery.py`: an `UPSTREAM_CREDITS` entry,
   `FAMILY_PROP_ORDER`, a `prop_spec` branch for any prop whose range or default
   differs from `PROP_SPECS`, `IGNORED_PROPS` for controls a spinner ignores,
   and `UPSTREAM_DEFAULTS` where a spinner's own default differs.
7. Add `assets/icons/<family>.svg` and its `.dlc-icon-<family>` rule in
   `assets/gallery.css`, then a row in the README's family table.
8. Update the counts: the family-count and component-count sentence at the top
   of the README, and `test_every_source_was_parsed` in
   `tests/test_packaging_metadata.py`.
9. If the family draws on a canvas, add it to `UNINSPECTABLE_FAMILIES` in
   `tests/test_gallery_controls.py` (there is no DOM state to compare; give it a
   paused-frame pixel check like `test_every_thinking_orbs_control_changes_the_canvas`
   so each control the page offers is shown to act) and to `NO_CSS_TEMPO` in
   `tests/test_contract.py`. Keep its loaders out of the always-animating header
   mark through `MARK_SKIP` in `gallery.py`. Header search rows clone a loader from
   that mark, so a canvas family needs a case in `preview()` in `assets/gallery.js`
   to show anything but its family icon.
